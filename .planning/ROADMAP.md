# Product Roadmap

## Milestone 1: Hyperlocal Living Foundation (Complete)
- **Phase 1: Communities & Location Privacy**
  - Physical PG/Hostel registry
  - Two-tier coordinate security model
  - Community request & approval lifecycle
- **Phase 2: Authentication & Profiles**
  - Google OAuth integration
  - Dual public/private profile separation

## Milestone 2: Group Grocery Delivery (Complete)
- **Phase 3: Group Carts Core**
  - Item manager and wishlists
  - Database lock enforcement triggers
  - Participant registration
- **Phase 4: Free Delivery Pooling & Embedding**
  - Host items upfront requirement
  - Store free delivery minimum threshold
  - Progress bar tracking remaining pool amount
  - Embedded carts in community cards
  - Handle-only anonymity in cart chat

## Milestone 3: Shared Transit (Complete)
- **Phase 5: Taxi Coordination**
  - Listing creation with gate pickup points
  - 4-stage atomic seat reservation lifecycle
  - Idempotent seat restoration & host controls
  - Private accepted-rider chat

## Milestone 4: Platform Polish & Mobile PWA (Complete)
- **Phase 6: Notifications & Mobile Hardening**
  - Notification bell with unread counter
  - Automated database triggers for residence alerts
  - WCAG AA accessibility compliance & touch target scaling
  - PWA configuration & offline manifest

## Milestone 5: Real-Time & Mobile Push (Upcoming)
- **Phase 7: Real-Time Subscriptions**
  - Replace HTTP polling with Supabase Realtime Channels
  - Optimistic UI updates
- **Phase 8: Mobile Push Notifications**
  - Web Push API integration for lock reminders and ride status changes
